# Frost Liner

Puts one MX Bikes bike's model swap on another bike, lined up on that bike's mounts.

## Install

Download `Frost-Liner-0.1.0-x64.exe` from [Releases](https://github.com/Frostn1/frost-liner/releases) and run it (Windows). It isn't signed yet, so Windows may show a warning: click More info, then Run anyway.
